# AgentHub Project

This is a WPF-based AgentHub application built with C# and .NET.

## Project Structure

- `Models/` - Data model classes
- `ViewModels/` - View Model classes following MVVM pattern
- `Services/` - Service layer for business logic
- `View/` - XAML view files

## Code Standards

CRITICAL: All code must follow the style guidelines defined in @StyleCop.md.

When writing or modifying C# code:
1. Read StyleCop.md for complete coding standards
2. Follow all StyleCop.Analyzers rules
3. Use Chinese for descriptions with English terminology in XML documentation
4. Always use `this.` prefix for instance members
5. Use `string.Empty` instead of `""`
